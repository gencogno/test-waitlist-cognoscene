developer handoff · revised mobile spec

intent: qualified email capture for desktop chrome. user must understand problem → solution → how → offer before form. ~6 scrolls on 390px — not ≤2.

  • structure — hero → problem → solution bridge → how (L1+L2+L3) → founding → form. order matches index.html. nothing removed.
  • hero — mini mock strip (not full stack). keep lead, chrome band, meta, mobile note.
  • problem — web h2 + shortened trap/loop + quote + 3 icons in one row. self-identification must land before form.
  • solution bridge — h2 + 3 layer pills only. drop subcopy ("working indefinitely…").
  • how — L1 + L3: 2-line copy, no video (premium features, name them). L2: full production copy + only tap-to-play video on mobile.
  • founding — compact card stays above form (scarcity + offer legitimacy).
  • form — stop the cycle headline, visible email label, merged checkbox (legal review), platform line, roadmap i sheet.

what compresses vs what stays full

  • remove: marquee animation only
  • compress: hero mocks, problem beats, bridge subcopy, L1/L3 copy, founding fine print
  • keep full: problem h2, L2 copy + video, founding offer, form emotional close

production mapping

  • index.html — @media (max-width: 760px) + .mobile-only blocks
  • form fields: production keeps ready + legal_agreed until legal approves merge
  • gate: #waitlistGateStatus · video: assets/videos/demo.mp4
